Learning Graphs
---
A graph $G = (V, E)$ with $n = \vert V \vert$ nodes is described by an adjacency matrix $\mathbf{A} \in \lbrace 0, 1 \rbrace^{n \times n}$ (or weighted $\mathbf{A} \in \mathbb{R}^{n \times n}$) and node features $\mathbf{X} \in \mathbb{R}^{n \times d}$. Define the degree matrix $\mathbf{D} = \text{diag} (\mathbf{A} \mathbf{1})$, the graph Laplacian $\mathbf{L} = \mathbf{D} - \mathbf{A}$, and its normalized version $\tilde{\mathbf{L}} = \mathbf{I} - \mathbf{D}^{-1/2} \mathbf{A} \mathbf{D}^{-1/2}$.

The fundamental structural constraint is that node indexing is arbitrary: for any permutation matrix $\mathbf{P}$, the pair $(\mathbf{P} \mathbf{A} \mathbf{P}^T, \mathbf{P} \mathbf{X})$ represents the same graph. A graph-level function must therefore be **permutation invariant**:

$$f (\mathbf{P} \mathbf{A} \mathbf{P}^T, \mathbf{P} \mathbf{X}) = f (\mathbf{A}, \mathbf{X}),$$

while a node-level function must be **permutation equivariant**:

$$f (\mathbf{P} \mathbf{A} \mathbf{P}^T, \mathbf{P} \mathbf{X}) = \mathbf{P} f (\mathbf{A}, \mathbf{X}).$$

These two symmetry requirements play the same role for graphs as translation equivariance plays for CNNs, and essentially dictate the message-passing architecture below.

Embedding
---
An embedding is a map from a discrete object (node, edge, graph) to a vector space, such that structural similarity becomes geometric proximity.

### Node Embedding

- Spectral methods (Laplacian eigenmaps) [[Belkin et al. 2003](https://ieeexplore.ieee.org/document/6789755)]: embed nodes with the eigenvectors of the $k$ smallest nonzero eigenvalues of $\tilde{\mathbf{L}}$, minimizing $\sum_{(u,v) \in E} \vert\vert \mathbf{z}_u - \mathbf{z}_v \vert\vert^2$ subject to orthogonality.

- Random-walk methods: DeepWalk [[Perozzi et al. 2014](https://arxiv.org/abs/1403.6652)] and node2vec [[Grover et al. 2016](https://arxiv.org/abs/1607.00653)] run (biased) random walks and train a skip-gram objective, so that nodes co-occurring in walks obtain similar embeddings:

$$\max_{\mathbf{Z}} \sum_{v \in V} \sum_{u \in N_{RW} (v)} \log \frac{\exp (\mathbf{z}_u^T \mathbf{z}_v)}{\sum_{w \in V} \exp (\mathbf{z}_w^T \mathbf{z}_v)}.$$

- GNN encoders: embeddings produced by message passing (see below), which unlike the shallow methods above are inductive — they generalize to unseen nodes/graphs because parameters are shared across nodes rather than stored per node.

### Edge Embedding
Edge representations are usually built from the incident node embeddings: $\mathbf{z}_{(u,v)} = \phi (\mathbf{z}_u, \mathbf{z}_v)$, where $\phi$ is symmetric for undirected graphs, e.g., Hadamard product $\mathbf{z}_u \odot \mathbf{z}_v$, average, or $\vert \mathbf{z}_u - \mathbf{z}_v \vert$ [[Grover et al. 2016](https://arxiv.org/abs/1607.00653)]. Some architectures maintain explicit edge features $\mathbf{e}_{uv}$ updated alongside node features (e.g., MPNN [[Gilmer et al. 2017](https://arxiv.org/abs/1704.01212)]).

### Graph Embedding
A graph-level representation is obtained by a permutation-invariant readout over node embeddings:

$$\mathbf{z}_G = R (\lbrace \mathbf{z}_v: v \in V \rbrace), \; R \in \lbrace \text{sum}, \text{mean}, \text{max}, \text{attention} \rbrace,$$

possibly hierarchically via differentiable pooling (DiffPool [[Ying et al. 2018](https://arxiv.org/abs/1806.08804)]). The classical alternative is graph kernels, notably the Weisfeiler-Lehman (WL) subtree kernel [[Shervashidze et al. 2011](https://www.jmlr.org/papers/v12/shervashidze11a.html)], which iteratively hashes neighborhood labels — the same computation pattern that upper-bounds GNN expressiveness (see GIN below).

Classification
---

### Node Classification
Semi-supervised setting: given labels on a subset $V_L \subseteq V$, predict the rest, with loss $\sum_{v \in V_L} \text{CE} (y_v, \text{softmax} (\mathbf{z}_v \mathbf{W}))$. The graph structure acts as a regularizer, implementing the homophily assumption that connected nodes tend to share labels. On heterophilic graphs this assumption fails and standard GNNs can underperform an MLP [[Zhu et al. 2020](https://arxiv.org/abs/2006.11468)].

### Edge Classification
Link prediction: score a candidate edge by $s (u, v) = \sigma (\mathbf{z}_u^T \mathbf{z}_v)$ (or an MLP on $\mathbf{z}_{(u,v)}$), trained with negative sampling on non-edges. Used for knowledge-graph completion and recommendation.

### Graph Classification
Predict a label per graph from $\mathbf{z}_G$ (molecule property prediction, protein function, etc.). Benchmarks: OGB [[Hu et al. 2020](https://arxiv.org/abs/2005.00687)].

Graph Neural Network (GNN)
---
The message-passing framework [[Gilmer et al. 2017](https://arxiv.org/abs/1704.01212)] unifies most architectures. At layer $k$:

$$\mathbf{h}_v^{(k+1)} = \text{UPD} \bigg(\mathbf{h}_v^{(k)}, \; \text{AGG} \big(\lbrace\!\lbrace \mathbf{h}_u^{(k)}: u \in \mathcal{N} (v) \rbrace\!\rbrace\big)\bigg),$$

where AGG is permutation invariant over the multiset of neighbors, which guarantees the equivariance of the whole network. Instances:

- GCN [[Kipf et al. 2017](https://arxiv.org/abs/1609.02907)]: symmetric-normalized mean aggregation,

$$\mathbf{H}^{(k+1)} = \sigma \big(\hat{\mathbf{D}}^{-1/2} \hat{\mathbf{A}} \hat{\mathbf{D}}^{-1/2} \mathbf{H}^{(k)} \mathbf{W}^{(k)}\big), \; \hat{\mathbf{A}} = \mathbf{A} + \mathbf{I}.$$

- GraphSAGE [[Hamilton et al. 2017](https://arxiv.org/abs/1706.02216)]: sampled-neighborhood aggregation for scalability, $\mathbf{h}_v^{(k+1)} = \sigma (\mathbf{W} \cdot [\mathbf{h}_v^{(k)} \Vert \text{AGG} (\lbrace \mathbf{h}_u^{(k)} \rbrace)])$.

- GAT [[Velickovic et al. 2018](https://arxiv.org/abs/1710.10903)]: attention-weighted aggregation,

$$\alpha_{uv} = \text{softmax}_{u \in \mathcal{N}(v)} \big(\text{LeakyReLU} (\mathbf{a}^T [\mathbf{W} \mathbf{h}_v \Vert \mathbf{W} \mathbf{h}_u])\big), \; \mathbf{h}_v' = \sigma \bigg(\sum_{u \in \mathcal{N}(v)} \alpha_{uv} \mathbf{W} \mathbf{h}_u\bigg).$$

- GIN [[Xu et al. 2019](https://arxiv.org/abs/1810.00826)]: sum aggregation with MLP update, $\mathbf{h}_v^{(k+1)} = \text{MLP} ((1 + \epsilon) \mathbf{h}_v^{(k)} + \sum_{u \in \mathcal{N}(v)} \mathbf{h}_u^{(k)})$. GIN is as expressive as the 1-WL test, and no standard message-passing GNN is more expressive — e.g., they cannot distinguish certain non-isomorphic regular graphs.

Two practical pathologies: **oversmoothing** — stacking many layers drives all node representations to a common value, since each aggregation step is (roughly) one step of diffusion along the graph [[Li et al. 2018](https://arxiv.org/abs/1801.07606), [Oono et al. 2020](https://arxiv.org/abs/1905.10947)]; and **oversquashing** — information from exponentially many distant nodes is compressed through bottleneck edges [[Alon et al. 2021](https://arxiv.org/abs/2006.05205)].

### Interactive illustration: message passing and oversmoothing

A few steps mix information along edges (useful); many steps wash all features to the global mean (oversmoothing).

(function () {
  try {
  var canvas = document.getElementById('gnndemo-canvas');
  if (!canvas) return;
  var ctx = canvas.getContext('2d');
  var W = canvas.width, H = canvas.height;
  var nodes = [], edges = [], feat = [], k = 0, auto = false, timer = null;
  function build() {
    nodes = []; edges = [];
    for (var c = 0; c < 2; c++) {
      var cx = c === 0 ? 170 : 430, cy = 190;
      for (var i = 0; i < 8; i++) {
        var a = 2 * Math.PI * i / 8;
        nodes.push({ x: cx + 95 * Math.cos(a), y: cy + 95 * Math.sin(a), c: c });
      }
    }
    for (var c2 = 0; c2 < 2; c2++) {
      var o = 8 * c2;
      for (var i2 = 0; i2 < 8; i2++) {
        edges.push([o + i2, o + (i2 + 1) % 8]);
        if (i2 % 2 === 0) edges.push([o + i2, o + (i2 + 3) % 8]);
      }
    }
    edges.push([0, 12]);
    reset();
  }
  function reset() {
    feat = [];
    for (var i = 0; i < nodes.length; i++) feat.push(nodes[i].c === 0 ? -1 : 1);
    k = 0;
    draw();
  }
  function neighbors(v) {
    var ns = [v];
    for (var i = 0; i < edges.length; i++) {
      if (edges[i][0] === v) ns.push(edges[i][1]);
      if (edges[i][1] === v) ns.push(edges[i][0]);
    }
    return ns;
  }
  function step() {
    var nf = [];
    for (var v = 0; v < nodes.length; v++) {
      var ns = neighbors(v), s = 0;
      for (var i = 0; i < ns.length; i++) s += feat[ns[i]];
      nf.push(s / ns.length);
    }
    feat = nf; k++;
    draw();
  }
  function color(h) {
    var t = Math.max(-1, Math.min(1, h));
    var r = Math.round(127 + 100 * t), b = Math.round(127 - 100 * t);
    return 'rgb(' + r + ',60,' + b + ')';
  }
  function draw() {
    ctx.clearRect(0, 0, W, H);
    ctx.strokeStyle = '#bbb';
    for (var i = 0; i < edges.length; i++) {
      var a = nodes[edges[i][0]], b = nodes[edges[i][1]];
      ctx.beginPath(); ctx.moveTo(a.x, a.y); ctx.lineTo(b.x, b.y); ctx.stroke();
    }
    for (var v = 0; v < nodes.length; v++) {
      ctx.fillStyle = color(feat[v]);
      ctx.beginPath(); ctx.arc(nodes[v].x, nodes[v].y, 14, 0, 2 * Math.PI); ctx.fill();
      ctx.strokeStyle = '#333'; ctx.stroke();
      ctx.fillStyle = '#fff'; ctx.font = '10px sans-serif';
      ctx.fillText(feat[v].toFixed(1), nodes[v].x - 9, nodes[v].y + 3);
    }
    var mean = 0, sd = 0;
    for (var j = 0; j < feat.length; j++) mean += feat[j] / feat.length;
    for (var j2 = 0; j2 < feat.length; j2++) sd += Math.pow(feat[j2] - mean, 2) / feat.length;
    document.getElementById('gnndemo-info').textContent =
      'layer k = ' + k + ', feature std = ' + Math.sqrt(sd).toFixed(3) +
      (Math.sqrt(sd) < 0.05 ? '  (oversmoothed!)' : '');
  }
  document.getElementById('gnndemo-step').addEventListener('click', step);
  document.getElementById('gnndemo-reset').addEventListener('click', function () {
    auto = false;
    if (timer) clearInterval(timer);
    document.getElementById('gnndemo-auto').textContent = 'Auto play';
    reset();
  });
  document.getElementById('gnndemo-auto').addEventListener('click', function () {
    auto = !auto;
    this.textContent = auto ? 'Stop' : 'Auto play';
    if (auto) timer = setInterval(step, 700);
    else if (timer) clearInterval(timer);
  });
  build();
  } catch (err) {
    var box = document.getElementById('gnndemo-box');
    if (box) {
      var msg = document.createElement('div');
      msg.style.color = '#c0392b';
      msg.style.marginTop = '6px';
      msg.textContent = 'Demo failed to start: ' + err.message;
      box.appendChild(msg);
    }
  }
})();

Beyond Message Passing
---
Higher-order GNNs based on $k$-WL [[Morris et al. 2019](https://arxiv.org/abs/1810.02244)], subgraph-based models, and graph transformers with structural encodings [[Rampasek et al. 2022](https://arxiv.org/abs/2205.12454)] trade scalability for expressiveness. On the efficiency side, graph condensation compresses the training graph itself — gradient matching [[Jin et al. 2022](https://arxiv.org/abs/2110.07580)] and distribution matching [[Liu et al. 2022](https://arxiv.org/abs/2206.13697)] both transfer directly from the image setting; see the GNN section of my [dataset condensation post](https://tongchen779.github.io/posts/dc/).
